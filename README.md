## Getting Started

run the development server:

```bash
npm install
npm run dev
```

Eslint config

```bash
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin eslint-config-next eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-tailwindcss
npx eslint --init
npm i @rocketseat/eslint-config
npm install -D prettier-plugin-tailwindcss
```
